# Java Ship It 🚚

**Java Ship It** — учебное консольное приложение для управления доставкой посылок.

Проект разработан на Java и демонстрирует применение принципов объектно-ориентированного программирования, наследования, полиморфизма, обобщённых типов и интерфейсов.

## 📌 О проекте

Приложение моделирует работу службы доставки, позволяя добавлять посылки различных типов, рассчитывать стоимость доставки, проверять сроки годности и отслеживать перемещение хрупких отправлений.

Посылки распределяются по коробкам в зависимости от типа. Для каждой коробки установлено ограничение по максимальному весу.

Основная задача проекта — реализовать систему, которая учитывает особенности разных типов отправлений и обеспечивает корректную обработку посылок.

## ✨ Основные возможности

- Добавление посылок в систему
- Поддержка нескольких типов отправлений
- Распределение посылок по коробкам
- Контроль максимального веса коробки
- Расчёт стоимости доставки
- Упаковка посылок
- Отправка посылок получателям
- Проверка срока годности скоропортящихся отправлений
- Отслеживание перемещения хрупких посылок
- Просмотр содержимого коробок
- Работа через консольное меню

## 📦 Типы посылок

В приложении реализованы три типа отправлений.

| Тип | Описание | Базовая стоимость |
|---|---|---:|
| `StandardParcel` | Обычная посылка | 2 |
| `PerishableParcel` | Скоропортящаяся посылка | 3 |
| `FragileParcel` | Хрупкая посылка | 4 |

Стоимость доставки рассчитывается исходя из веса посылки.

### Обычные посылки

Обычные отправления не имеют дополнительных ограничений.

Для них предусмотрены:
- Упаковка
- Отправка
- Расчёт стоимости доставки

### Скоропортящиеся посылки

Скоропортящиеся отправления имеют ограниченный срок годности.

При отправке приложение проверяет, не истёк ли срок годности посылки.

Если срок годности истёк, отправка невозможна.

### Хрупкие посылки

Хрупкие отправления требуют дополнительной защиты при упаковке.

Для них предусмотрены:
- Упаковка в защитную плёнку
- Отслеживание перемещения
- Отображение нового местоположения

## 💰 Расчёт стоимости доставки

Стоимость доставки зависит от типа посылки и её веса.

Используется следующая формула:

\[
\text{Стоимость доставки}
=
\text{Базовая стоимость}
\times
\text{Вес посылки}
\]

Пример:

| Тип посылки | Вес | Стоимость |
|---|---:|---:|
| Обычная | 100 г | 200 |
| Скоропортящаяся | 100 г | 300 |
| Хрупкая | 100 г | 400 |

Таким образом, для обычной посылки весом 100 грамм стоимость доставки составит:

\[
2 \times 100 = 200
\]

## 📦 Управление коробками

Для каждого типа посылок предусмотрена отдельная коробка.

| Тип коробки | Максимальный вес |
|---|---:|
| Для обычных посылок | 5000 г |
| Для хрупких посылок | 500 г |
| Для скоропортящихся посылок | 2000 г |

При добавлении посылки приложение проверяет, не будет ли превышен допустимый вес коробки.

Если ограничение превышено, посылка не добавляется в коробку.

Для работы с коробками используется обобщённый класс `ParcelBox<T>`, который позволяет хранить посылки определённого типа.

## 🏗 Архитектура проекта

Приложение построено на основе объектно-ориентированного подхода.

### Иерархия классов

```text
                  Parcel (abstract)
                       |
          +------------+------------+
          |            |            |
   StandardParcel  PerishableParcel  FragileParcel
                                       |
                                    Trackable
```

### Основные классы

| Класс | Назначение |
|---|---|
| `DeliveryApp` | Точка входа и консольный интерфейс |
| `Parcel` | Абстрактный базовый класс посылки |
| `StandardParcel` | Обычная посылка |
| `PerishableParcel` | Скоропортящаяся посылка |
| `FragileParcel` | Хрупкая посылка |
| `ParcelBox<T>` | Обобщённый класс для хранения посылок |
| `Trackable` | Интерфейс для отслеживания отправлений |

### Применяемые принципы ООП

**Наследование**

Все типы посылок наследуются от абстрактного класса `Parcel`.

**Полиморфизм**

Каждый тип посылки реализует собственный метод `getBaseCost()`, определяющий базовую стоимость доставки.

**Абстракция**

Общий функционал посылок вынесен в абстрактный класс `Parcel`.

**Интерфейсы**

Интерфейс `Trackable` определяет поведение для отслеживания отправлений.

**Обобщённые типы**

Класс `ParcelBox<T>` использует параметр типа, ограниченный классом `Parcel`, что обеспечивает типобезопасность при работе с коробками.

## 🚀 Запуск проекта

### Требования

Для запуска приложения необходимы:

- JDK 21 или выше
- Apache Maven
- IntelliJ IDEA или другая Java IDE

### Клонирование репозитория

```bash
git clone https://github.com/YuryShlyahov/java-ship-it.git
cd java-ship-it
```

### Сборка проекта

Выполните команду:

```bash
mvn clean package
```

### Запуск приложения

Запустите класс `DeliveryApp` из IDE.

Также можно выполнить запуск через Maven:

```bash
mvn compile exec:java \
  -Dexec.mainClass="ru.yandex.practicum.delivery.DeliveryApp"
```

После запуска появится консольное меню приложения.

## 🖥 Консольное меню

При запуске приложения пользователю доступны следующие действия:

```text
Выберите действие:
1 — Добавить посылку
2 — Отправить все посылки
3 — Посчитать стоимость доставки
4 — Отследить посылку
5 — Показать отправления в коробке
0 — Завершить
```

### Пример работы

Пользователь может добавить посылку, указав:

- Тип отправления
- Описание
- Вес в граммах
- Адрес доставки
- Дату отправки
- Срок годности (для скоропортящихся посылок)

После добавления посылки приложение помещает её в соответствующую коробку, если позволяет ограничение по весу.
